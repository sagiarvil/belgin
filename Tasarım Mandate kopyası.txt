1. Foundation Layer (Temel Katman)
A. Design Token Architecture
	•	Renk, tipografi, boşluk ve animasyon token'ları: Her değer değişkenle tanımlanmalı, sabit değer kullanılmamalı. Bu, marka tutarlılığını ve gelecekteki güncellemeleri garanti eder. 
	•	8px bazlı grid sistemi: Tüm padding, margin, boyutlandırma 8'in katları olmalı.
B. Tipografi Sistemi
	•	Maksimum 2 font ailesi (birincil ve ikincil). 
	•	Hiyerarşik ölçeklendirme: H1'den caption'a kadar kesin boyut, ağırlık ve satır aralığı değerleri.
	•	Responsive tipografi: Breakpoint'lere göre otomatik ölçeklenen clamp() değerleri.

2. Semantic & AI/LLM-Ready HTML Structure
A. Semantik HTML5 Zorunluluğu
	•	<header>, <nav>, <main>, <article>, <section>, <aside>, <footer> gibi anlamsal etiketler zorunlu. <div> sadece gerçekten gerekli olduğunda kullanılmalı. 
	•	Tek bir <h1> sayfa başına; <h2> → <h3> → <h4> sıralaması atlanmadan devam etmeli. 
B. LLM/AI Crawler Optimizasyonu
	•	JSON-LD Structured Data: Her sayfada @context: "https://schema.org" ile makine tarafından okunabilir veri. Article, Product, FAQPage, Organization, BreadcrumbList gibi tipler zorunlu. 
	•	Server-Side Rendering (SSR): LLM crawler'ları JavaScript çalıştırmaz. İçerik HTML'de doğrudan sunulmalı, client-side hydration sonrası değil. 
	•	<time datetime="YYYY-MM-DD">: Makine tarafından okunabilir tarih formatı. 

3. Component Library & States
A. Bileşen Spesifikasyonu
Her bileşen için şunlar tanımlanmalı:
	•	Tüm durumlar (states): default, hover, active, focus, disabled, loading, error
	•	Responsive davranış: Breakpoint'lerde nasıl değiştiği
	•	Erişilebilirlik (ARIA): aria-label, aria-labelledby, role tanımları, keyboard navigasyonu 
B. Form & Input Standartları
	•	<label for="..."> zorunlu, placeholder asla label yerine geçemez.
	•	<fieldset> + <legend> ile gruplama.
	•	Hata mesajları: inline, renk + ikon + metin (sadece renk değil).

4. Accessibility & Compliance (Erişilebilirlik)
A. WCAG 2.1 AA (Minimum) / AAA (Tercih)
	•	Renk kontrastı: 4.5:1 minimum (metin), 3:1 (büyük metin/UI).
	•	Klavye navigasyonu: Tüm interaktif elemanlar Tab ile erişilebilir.
	•	Screen reader uyumluluğu: ARIA landmark'ları, atlama linkleri (skip to content), anlamlı alt metinler. 
B. European Accessibility Act (EAA) Uyumu
2025 itibarıyla AB pazarı için yasal zorunluluk. 

5. Performance & Technical Architecture
A. Core Web Vitals (CWV) Hedefleri
	•	LCP (Largest Contentful Paint): < 2.5s
	•	FID/INP (Interaction): < 200ms
	•	CLS (Cumulative Layout Shift): < 0.1
B. Güvenlik & Governance
	•	Role-Based Access Control (RBAC): CMS'de kim neyi düzenleyebilir?
	•	SSO + MFA: Enterprise standart.
	•	SOC 2 / GDPR / CCPA: Veri işleme ve gizlilik politikaları. 

6. Documentation & Governance (Dokümantasyon)
A. Machine-Readable Documentation
	•	Model Context Protocol (MCP): AI ajanlarının design system'i anlayabilmesi için yapılandırılmış dokümantasyon. 
B. Living Document
	•	Versiyonlama: Semantic versioning (v1.0.0, v1.1.0).
	•	Contribution model: Kim nasıl bileşen önerebilir, review süreci nedir?
	•	Do / Don't örnekleri: Her bileşen için görsel yanlış/ doğru kullanım örnekleri. 

7. Multi-Platform & Scalability
A. Responsive & Adaptive
	•	Breakpoint sistemi: Mobile-first, minimum 3 breakpoint (tablet, desktop, wide).
	•	Fluid typography & spacing: Piksel değil, rem, em, vw/vh, clamp().
B. CMS & Integration Ready
	•	Headless / API-first CMS: Content model'ı frontend'den bağımsız.
	•	CRM/ERP/SSO entegrasyonları: Önceden tanımlı API endpoint'leri ve veri modelleri.

	•	<main> — Sayfa başına tek adet.

7. TYPOGRAPHIC LAW
7.1 Font Governance
	•	Maksimum 2 font ailesi: Birincil (body) ve İkincil (display/headings).
	•	Font yükleme: font-display: swap zorunlu; FOIT (Flash of Invisible Text) yasaktır.
	•	Subset: Kullanılan karakter setine göre alt küme (Latin Extended vb.) yüklenmeli.
7.2 Fluid Typography Scale
css


/* Zorunlu pattern */
--font-size-hero: clamp(2.5rem, 5vw + 1rem, 4.5rem);
--font-size-h1: clamp(2rem, 4vw + 0.5rem, 3.5rem);
--font-size-body: clamp(1rem, 0.5vw + 0.875rem, 1.125rem);

	•	Piksel (px) birimi tipografi için yasaktır; rem veya em zorunlu.
	•	Satır aralığı (line-height): Body 1.5, Headings 1.2–1.3.
7.3 8px Grid System
	•	Tüm padding, margin, gap, width, height değerleri 8px'in katları olmalıdır.
	•	Tek istisna: 4px (yarım adım) mikro-düzenlemeler için kullanılabilir.
	•	Baseline grid: Tipografi, 4px baseline grid'e hizalanmalıdır.

9.2 Sensitivity Analysis
Her bileşen için "Sensitivity Chart" dokümante edilmelidir:

11. AI/LLM READINESS SPECIFICATION
11.1 Content Model for Machine Inference
	•	Başlık hiyerarşisi: Makine tarafından outline olarak okunabilir olmalı.
	•	Listeler: <ul>/<ol> ile yapılandırılmış veri; virgülle ayrılmış metin değil.
	•	Tablolar: <table> ile semantic tablo; görsel düzen aracı olarak <table> kullanımı yasaktır.
	•	Linkler: href mutlaka anlamlı olmalı; "tıklayın", "burada" anchor text yasaktır.
11.2 URL Architecture
	•	Kebab-case: /user-profile/settings (doğru) vs /userProfile/settings (yanlış)
	•	Semantic slug: ID'ler UUID değil, anlamlı tanımlayıcı olmalı (örn: /blog/design-system-mandate).
